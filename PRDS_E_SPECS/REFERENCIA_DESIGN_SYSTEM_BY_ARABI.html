Ponto de partida

Cinco decisões que o código revela

Antes dos tokens, o que o CSS mostra sobre como a marca pensa. Estas são as regras que fazem uma tela "parecer By Arabi" mesmo antes de acertar o hex.

Medido

Serif leve, nunca negrito

Todo título é Georgia, serif com font-weight: 400 e letter-spacing negativo (−.045em a −.05em). O peso vem do tamanho, não da espessura. Título em bold quebra a marca imediatamente.

Medido

Zero dependência de fonte

Não existe um único @font-face nem link para Google Fonts na folha. Georgia para títulos, Helvetica Neue/Arial para corpo — ambas do sistema. Suas apps HTML sem build step herdam isso de graça: nada para carregar, nada para quebrar.

Medido

O fundo alterna, sempre

Nenhuma seção repete o fundo da anterior. A sequência real é papel → branco → papel fundo → tinta. É isso que dá ritmo à página sem precisar de bordas, sombras ou cards decorativos.

Medido

Imagem não tem canto arredondado

Cards de projeto, ambiente e vídeo usam border-radius: 0. O arredondamento existe só em controles (pílulas de 999px) e em cartões de formulário (14–20px). Foto é foto; interface é interface.

Medido

Acessibilidade já estava lá

:focus-visible com contorno dourado de 3px e offset de 4px, e um bloco prefers-reduced-motion que desliga todas as animações. Não é enfeite do sistema — é comportamento existente que precisa ser mantido.

Medido

Movimento curto e uniforme

Toda transição do site está entre .15s e .18s. Hover levanta o elemento em 2–3px. Não há easing exótico nem duração longa em interface — as animações lentas ficam só nas mídias de fundo.

Cor

Ouro sobre papel e ouro sobre tinta

A paleta inteira do site tem duas famílias: um ouro e uma escala de neutros quentes. Não há verde, azul ou vermelho em lugar nenhum — o site institucional nunca precisou comunicar estado.

O ouro tem dois valores, e essa é a regra que mais importa

Sobre tinta, #e3b838 tem contraste de 9,9:1 — folgado. Sobre papel, o mesmo ouro fica praticamente ilegível, e por isso o site troca para #a77d0b nos fundos claros. Só que #a77d0b sobre papel dá 3,3:1: passa para título grande, não passa para texto pequeno. O site escapa disso porque só usa o ouro claro em títulos e números grandes. Uma aplicação interna com rótulo dourado de 12px não escapa.

Botões

Três variantes, uma geometria só: pílula de 999px, altura mínima 54px, peso 850, e um gap: 20px entre rótulo e seta — esse respiro largo é parte da assinatura. O botão dourado é o mesmo nos dois fundos; o botão contornado troca de ouro; o botão escuro só existe em fundo claro.

Campo de formulário

Layout e movimento

Uma faixa, um respiro, três quebras

A técnica de faixa do site

O site não usa container com margin: auto. Cada seção tem padding lateral calculado, o que centraliza o conteúdo e garante margem mínima no celular em uma linha só. Esta página inteira usa exatamente isso. 

.section{
  padding: 112px max(28px, 50vw - 620px);
}
/* ≤840px */  padding-block: 80px;
/* ≤590px */  padding-inline: 19px;

Conteúdo resultante: 1240px de largura máxima. Os breakpoints do site são 1080px, 840px e 590px — não os do Bootstrap ou do Tailwind padrão.

Movimento

  • Transições de interface: .15s a .18s. Nada mais longo.
  • Hover: translateY(-2px) em contornado, -3px em preenchido.
  • Entrada na viewport: opacidade + translateY(14–18px), via animation-timeline: view() — CSS puro, sem observer.
  • Fundo de herói: zoom de 18s, único movimento longo do site.
  • Redução: um bloco prefers-reduced-motion zera animação, transform e transição de tudo.
@media (prefers-reduced-motion:reduce){
  html{scroll-behavior:auto}
  *,::before,::after{
    opacity:1!important; transition-duration:.01ms!important;
    animation:none!important; transform:none!important;
  }
}
Proposta — não existe no site

O que as aplicações internas precisam a mais

Um site institucional apresenta; uma ferramenta operacional informa estado. O site não tem nenhuma cor semântica porque nunca precisou dizer "pendente", "liberado" ou "com erro". Esta parte é acréscimo meu, construída para conviver com o ouro.

Cores de estado

A restrição difícil: o ouro já ocupa a faixa do âmbar, então "atenção" não pode ser amarelo — ficaria indistinguível do acento da marca. Por isso o aviso vai para terracota queimada, que dialoga com a madeira sem competir com o ouro.

Liberado — #2f6b45 claro · #5faa7c escuro · 5,6:1
Pendência — #9a5b1f claro · #e2934a escuro · 4,8:1
Bloqueado — #a32f2b claro · #f0736d escuro · 6,2:1
Liberado Pendência Bloqueado

Regra de ouro literal: estado nunca é dourado. O ouro é identidade e ação principal. Se um status usar ouro, o operador perde a única pista visual confiável de "isto é o botão que resolve".

O que mais falta mapear

  • Tabela densa. O site tem uma linha de loja de 102px de altura — generosa demais para uma lista de 200 contratos. Precisa de uma variante compacta.
  • Estado vazio e carregando. Inexistentes no site.
  • Densidade de formulário. O campo de 48px é confortável para 4 campos, cansativo para 40.
  • Impressão e PDF. O checklist gera PDF; papel de verdade não é #f5f0e6.
  • Gráfico e indicador. Nenhuma referência no site.

O ponto sensível é a escala de etapas. As cinco cores de passo (--step1 a --step5) carregam informação real na tela de processos, e a marca não tem cinco cores para oferecer. Trocar isso não é substituição de token: é redesenho de como a etapa é comunicada — provavelmente por numeração serif e peso de linha, como o site faz na lista de processo, em vez de matiz.

Logo

Só existe versão para fundo escuro

O site publica dois arquivos de logo. Nos dois, as palavras "BY" e "ARABI" são brancas — só a curva, o "Y" e "PLANEJADOS" são dourados. Não há versão para fundo claro, que é justamente o modo padrão da marca.

Sobre tinta — funciona

Sobre papel — o nome desaparece

Os dois quadros acima carregam exatamente o mesmo arquivo (by-arabi-logo-horizontal.png, 532×220, RGBA). A diferença é só o fundo. Enquanto não existir uma versão do logo para fundo claro, telas em modo papel devem usar a curva dourada com o nome em Georgia — nunca o PNG.

A curva com a esfera é o gesto central da marca e funciona nos dois fundos, porque é dourada. O site usa uma redução dela: um filete de 70×1px em #e3b838 como assinatura sob o herói.

Estado

O que já foi decidido

Decidido

Papel é o padrão

Ferramentas internas, páginas de cliente e relatórios nascem em modo papel, como o site. Tinta passa a ser variante para telas de destaque e seções de contraste dentro de uma página clara.

Feito

A skill foi reescrita

byarabi-design existia com valores que não batiam com o site — nenhuma das cores era igual, e o ouro do tema claro dela dava 1,84:1, ilegível. Agora carrega os valores medidos e a regra dos três ouros.

Aberto

Escala de etapas

Continua sendo o problema difícil: telas de processo precisam distinguir 4–6 passos e a marca tem um acento só. Os tons de madeira e verde são paliativo, não solução.
